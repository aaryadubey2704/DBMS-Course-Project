DO THIS FIRST

1. Extract the ZIP.
2. Start MySQL in XAMPP.
3. Open phpMyAdmin or MySQL client.
4. Run Database/tailoring_boutique.sql completely.
5. Confirm database `tailoring_boutique` exists.
6. In UI/config.py, change password if your MySQL root account has one.
7. Open terminal inside UI:
   pip install -r requirements.txt
   python app.py
8. Test the Customers tab:
   - insert a new customer
   - refresh
   - show it in MySQL
   - delete it
   - refresh and show it removed
9. For the final PPT, replace the two member placeholders and add real screenshots/GitHub link.
